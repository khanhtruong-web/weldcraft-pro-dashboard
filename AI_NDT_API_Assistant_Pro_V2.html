How to get a Client ID?
  1. Go to Google Cloud Console and create a project.
  2. Go to APIs & Services > Library. Enable exactly two APIs: Google Drive API and Google Sheets API.
  3. Go to OAuth consent screen and configure it as External.
  4. Go to Credentials, click Create Credentials > OAuth client ID.
  5. Choose Web application. Add your current URL (e.g., http://localhost or https://your-domain.com) to Authorized JavaScript origins.
  6. Copy the generated Client ID and paste it below.
