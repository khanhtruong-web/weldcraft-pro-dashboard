⭐ CATEGORY 1: Source-Grounded AI with Inline Citations (NotebookLM Core)
The #1 most important NotebookLM feature. Currently, the AI chat just sends raw queries to Gemini with ZERO context from uploaded documents.
Feature
Description
1.1 Document Text Extraction
When PDF/DOCX is uploaded, extract full text and store in IndexedDB alongside the file blob
1.2 RAG-Style Context Injection
When user asks a question, include relevant source text chunks in the Gemini prompt
1.3 Inline Citations
AI responses include [Source: ASME V, p.42] clickable references that scroll the PDF reader to that location
1.4 Multi-Source Cross-Reference
AI can synthesize answers across ALL sources in a notebook, not just one
1.5 Source Confidence Indicator
Show confidence badge (🟢 High / 🟡 Medium / 🔴 Low) based on how well the answer matches sources
1.6 "Ask about this page"
Button in PDF reader that captures current page text and sends it as context to AI
Technical Approach:
Upload PDF → PDF.js getTextContent() → Store text chunks in IndexedDB
User asks question → Retrieve all source texts → Build system prompt:
  "You are a technical assistant. Answer ONLY based on these sources:
   [Source 1: ASME V] ... text chunks ...
   [Source 2: API 1104] ... text chunks ...
   Always cite your sources as [Source: name, page X]"
